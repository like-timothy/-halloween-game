# 10월 31일의 비밀 — 실시간 미스터리 방탈출

## 배포
GitHub 저장소 최상위에 `server.js`, `package.json`, `render.yaml`, `public/index.html`을 업로드합니다. Render → Web Service → 저장소 연결 → Build Command `npm install` → Start Command `npm start` → Deploy.

## 사용
- 교사: 배포된 사이트 주소로 접속 → **교사 게임방 만들기** → QR 표시 → 학생 입장 후 **탐험 시작**.
- 학생: QR코드로 접속 → 닉네임 → 참여하기 → 인원 및 개인 환영 멘트가 표시되는 대기실.
- 각 방에서 학생은 그림 속 물건을 터치하여 한 번 답을 제출합니다. **타이머가 없으며** 교사가 **정답과 해설 공개**를 누를 때 공개됩니다. 교사가 **다음 방으로**를 누르면 다음 미션이 시작됩니다.
- 마지막 방은 종교개혁 관련 문제 한 개입니다. 그 전 세 문제는 가을 축제의 날짜·어원·상징물에 관한 내용입니다.

## 주의
- 학생용 QR 접속 주소에 `?code=123456`이 포함되어 학생에게는 교사 게임방 만들기 버튼이 보이지 않습니다.
- Render 무료 서버는 사용하지 않을 때 잠들 수 있습니다. 수업 전 교사와 학생 태블릿으로 시험하세요.
- 서버 재시작이나 교사 연결 종료 시 게임방은 종료됩니다. 수업 중 배포하지 마세요.
- 서버 메모리에 게임 진행 상태를 저장하므로 단일 인스턴스로 운영하세요.
- 서버 측 자동 타이머는 없습니다.
