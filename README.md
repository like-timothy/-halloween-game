# 🎃 할로윈 미스터리 — 10월 31일의 비밀

여중 종교수업용 실시간 멀티플레이 퀴즈입니다.

## 실행하기

Node.js 18 이상 설치 후 이 폴더에서:

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 학생들과 실시간 참여하기

학교 내 여러 태블릿에서 접속하려면 외부에서 접근 가능한 주소가 필요합니다. Node.js 웹 서버를 지원하는 호스팅 서비스(Render, Railway 등)에 이 폴더를 배포한 후, 배포된 HTTPS 주소를 학생들에게 QR 코드로 공유하세요. 학생들은 같은 주소에 접속하여 6자리 코드를 입력합니다. 교사는 **교사 · 게임방 만들기**를 누릅니다.

주의: 로컬 컴퓨터에서만 `localhost`를 열면 다른 태블릿은 접속할 수 없습니다. 교사용 브라우저를 닫거나 연결이 끊기면 방이 종료됩니다. 무료 호스팅에서는 서버가 잠들거나 재시작되면 방이 사라질 수 있습니다.

## 특징

- 6자리 참여 코드, 닉네임, 6문제, 문제당 15초
- 실시간 응답 집계, 정답 공개, 점수 순위
- 첫 문제는 정답 없는 투표
- 점수: 정답당 500점 + 속도 보너스 최대 500점
- 게임 종료 후 다시 시작
- 참여 최대 100명 / 방 (실제 동시 접속 성능은 서버 사양에 따라 다름)

## 역사적 표현

95개조 반박문 발표일은 1517년 10월 31일입니다. 비텐베르크 성교회 문 게시 여부는 역사학계에서 논의가 있어 게임에서는 단정하지 않습니다. 면벌부는 본래 '돈으로 죄 자체를 용서받는 증서'가 아니었으나 당시 판매와 설교의 남용이 비판 대상이 되었습니다.

## 인터넷 공개 배포 (Render)

1. GitHub에 새 저장소를 만들고 압축 해제한 폴더 안의 파일들을 업로드합니다 (`server.js`, `package.json`, `render.yaml`, `public/` 등).
2. Render에서 **New → Blueprint**를 선택하고 해당 GitHub 저장소를 연결합니다. `render.yaml`을 인식하면 웹서비스 생성 절차가 시작됩니다.
3. 배포가 끝나면 Render가 제공하는 `https://...onrender.com` 주소를 교사용 브라우저에서 엽니다.
4. **교사 · 게임방 만들기**를 누르면 6자리 코드와 학생 참여용 QR코드가 자동 표시됩니다. 학생은 QR코드를 스캔하고 닉네임을 입력합니다.

**중요:** 이 파일만으로 공개 사이트가 자동 생성되지는 않습니다. Render 및 GitHub 계정에서 최초 배포가 필요합니다. 무료 인스턴스는 대기 후 첫 접속이 느릴 수 있으며 서버가 재시작되면 진행 중인 게임방이 사라집니다. 수업 전에 여러 기기로 테스트해 주세요.
